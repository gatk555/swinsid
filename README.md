This is a fork of dmantione/swinsid, where Daniël Mantione provided an
annotated source code for the Swinsid firmware.  Here that code is modified
to try and improve it.  In branch "comments" the changes are limited so that
the original firmware can still be built.  On this main branch the changes
are more radical.

Hex files for use without building are in directory "hex_files".
